Elite Features

Today's Damage

Messages, sessions, and tool calls. See exactly how hard you've been running Claude today.

7-Day Rhythm

A rolling week of activity. Are you consistent or feral? The chart knows.

Token Breakdown

Input, output, and cache usage by model. Know where your tokens are going.

How it works

Reads the stats file Claude Code already keeps at ~/.claude/stats-cache.json and watches for changes.
